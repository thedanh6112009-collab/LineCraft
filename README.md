# LineCraft — Ứng dụng ghi chú viết tay & phác thảo

**Phiên bản hiện tại:** `v1.2.8`  
**Nền tảng:** Windows 10 / Windows 11 (x64)

> Kho lưu trữ này chỉ dùng để phát hành bộ cài đặt và cập nhật tự động cho **LineCraft** (không công khai mã nguồn).

## Tải xuống & Cài đặt
- Tải file **`LineCraft_v1.2.8_Setup.exe`** (hoặc bản chạy độc lập **`LineCraft.exe`**) tại mục **[Releases](https://github.com/thedanh6112009-collab/LineCraft/releases/latest)**.
- Chạy `LineCraft_v1.2.8_Setup.exe` để mở trình cài đặt chuyên nghiệp vào máy tính kèm lối tắt Desktop & Start Menu.

## Tự động cập nhật theo tag Release
- Mỗi khi có tag phát hành mới (`vX.Y.Z`) trên trang Releases, ứng dụng **LineCraft** sẽ tự động kiểm tra và thông báo bản cập nhật mới ngay bên trong phần mềm (hoặc bấm **Kiểm tra cập nhật** trong biểu tượng giọt nước).
- Nhấn **Tải & Cập nhật ngay** để tự động tải bộ cài mới nhất và nâng cấp tại chỗ.
